# Keyboard reference

The site supports vim-style chord shortcuts when JavaScript is enabled. Press the first key, then the second within 1.5 seconds.

## Navigation chords

| Chord | Destination |
|------:|:------------|
| `g` &rarr; `h` | [Home](/) |
| `g` &rarr; `p` | [Projects](/projects/) |
| `g` &rarr; `r` | [Resume](/resume/) |
| `g` &rarr; `n` | [Now](/#now) |

## Other keys

| Key | Action |
|-----:|:-------|
| `?` | Open or close the shortcut dialog |
| `Esc` | Close the dialog (it also has a Close button) |

## On a Mac

Safari only moves to text fields when you press Tab, and Firefox follows the Mac's own keyboard setting, so on most sites Tab seems to skip every link and button. With JavaScript on, this site puts its links and buttons back into Safari's Tab order itself. Elsewhere, hold Option while pressing Tab, or turn on Safari &rarr; Settings &rarr; Advanced &rarr; "Press Tab to highlight each item on a web page". For Firefox and every other app, turn on System Settings &rarr; Keyboard &rarr; "Keyboard navigation".

Shortcuts are ignored when focus is inside an input, textarea, select, or contenteditable element. The site is fully usable without JavaScript &mdash; this layer is progressive enhancement only.
