# Keyboard reference

The site supports vim-style chord shortcuts when JavaScript is enabled. Press the first key, then the second within 1.5 seconds.

## Navigation chords

| Chord | Destination |
|------:|:------------|
| `g` &rarr; `h` | [Home](/) |
| `g` &rarr; `w` | [Writing](/writing/) |
| `g` &rarr; `p` | [Projects](/projects/) |
| `g` &rarr; `r` | [Resume](/resume/) |
| `g` &rarr; `n` | [Now](/now/) |

## Other keys

| Key | Action |
|-----:|:-------|
| `?` | Toggle this shortcut overlay |
| `Esc` | Close the overlay |

Shortcuts are ignored when focus is inside an input, textarea, select, or contenteditable element. The site is fully usable without JavaScript &mdash; this layer is progressive enhancement only.
