Colophon

How this site is built.

What this site is

sebthecanadian.ca is a minimal personal “front door” site: a stable identity page with durable links to the places I publish and work.

Where the real writing lives

The primary body of notes and writing lives in the garden: cognitivearchitecture.ca.

Hosting and deployment

  • Hosted on GitHub Pages from the main branch (root folder).
  • Custom domain managed via Cloudflare DNS.
  • HTTPS enforced at the GitHub Pages layer.

Design approach

  • Static HTML, minimal moving parts.
  • Portable by default (easy to migrate to another host later).
  • Light IndieWeb conventions (e.g., basic identity markup, durable URLs).
